# Stars777 Homepage Clone

A lightweight, standalone, and pixel-perfect clone of the **[Stars777.org](https://stars777.org/) homepage only**.

---

## 🚀 What Is Included (Homepage Only)

- **Header & Navigation**: Brand logo, navigation menu, and "Download App" button.
- **Hero Section**: "Winning is a Habit" banner, live Aviator multiplier ticker (`5.00x Live Multiplier`), and "PLAY NOW" CTA.
- **Jackpot Section**: Dynamic total prize pool counter, real-time animated cards for featured jackpot games.
- **FAQ Accordion**: Interactive questions & answers with collapsible state and side artwork.
- **About Us Section**: Detailed company overview, platform highlights, and side artwork.
- **Featured Game Reviews**: 3 featured homepage game cards.
- **Blog Section**: 4 featured homepage blog cards.
- **Customer Reviews Carousel**: Interactive player review slider with 5-star ratings and next/previous controls.
- **Footer**: Brand disclaimer, quick links, legal/support links, social links, security badges, and payment/withdrawal channels (UPI, Paytm, Visa, MasterCard).

## 🛠️ How to Run

1. Open terminal in `f:/777-homepage`.
2. Run:
   ```bash
   npm start
   ```
3. Open your browser at **`http://localhost:3005`**.
